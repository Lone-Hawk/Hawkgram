Support Hawkgram
================

Hawkgram is a free and open source project developed by Lone Hawk.
If you enjoy Hawkgram and would like to show your appreciation, starring the `GitHub repository <https://github.com/Lone-Hawk/Hawkgram>`_,
sharing the project with others and `reporting issues <https://github.com/Lone-Hawk/Hawkgram/issues>`_ you find are great ways to help it grow.
